# i18n

> State of localization for this project.

## Languages

**`es-ES` only, and that is a decision, not a gap.** The humor is specifically
about Spanish public EV-charging culture; an English translation would lose the
joke and double the copy surface for no audience.

## Rules

- UI strings are written directly in Spanish inside components — there is no
  dictionary layer, no localized routes, no hreflang generation.
- Copy rules (tone, no brands) live in `docs/frontend/COPYWRITING.md`.
- **If localization is ever requested**, it is a new feature decision: strings
  must first move to dictionaries, and `COPYWRITING.md` remains the tone
  authority per locale. Do not introduce a translation layer silently in a
  feature that has another purpose.
